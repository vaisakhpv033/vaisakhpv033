### 💡 Executive Summary

I build **production-grade AI systems, real-time voice infrastructure, and resilient full-stack backends**. 

My core focus bridges **low-latency telephony/voice agents** with **intelligent LLM orchestration**—from self-hosting open-source LLMs (like Qwen) via **vLLM** for high-throughput inference, to integrating frontier models (Gemini, Claude, GPT-4) based on enterprise latency, cost, and accuracy SLAs.
